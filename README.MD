# RitsukageGif

用于屏幕录制、截图标注和动图编辑。

启动程序后，选择录制区域，再开始录制；帧率、缩小倍率和输出格式可在主界面调整。截图可从托盘菜单或功能动作启动。

预设用于保存捕获范围、布局和输出规则。从主界面的“预设”菜单打开编辑器，可编写、运行和调试脚本。
