# Avalonia.Native 12.1.4 source dependency

This directory contains the Avalonia.Native managed wrapper from AvaloniaUI/Avalonia tag12.1.4, commit2d79ba55fae1b1e71c69f93a668080c9029e6a31. Original third-party C# source, avn.idl, signing key and MIT license are retained under vendor/. All49 C# source files use block-scoped namespaces;17 upstream file-scoped declarations were mechanically normalized without changing using scope or member order. The local functional changes are: ClipboardDataFormatHelper exposes native public.png as both the existing Bitmap format and encoded bytes, preserving the original sender-provided drag/clipboard session for APNG and HDR data; the mounted-volume listener disposes its owned polling timer on the first Dispose call, retaining the existing idempotence guard.

Configured source cleanup normalizes syntax and private names, removes unreachable managed helpers, and narrows internal implementation members. Public desktop registration/options and MicroCom-generated partial contracts remain intact. Explicit native ownership, callback initialization, cache fields and the three geometry hint reads retain necessary local inspection suppressions. Source member/property order is preserved; the IDL, native struct/vtable layout and relative static initialization order are unchanged. Compile items link vendor/src to the original logical root so namespaces keep their upstream identities without disabling namespace checks.

The standalone project builds this wrapper only. It uses matching official Avalonia12.1.4 implementation assemblies and MicroCom0.11.6 IDL generator/runtime; it does not reference upstream framework or Xcode projects. Official reference assemblies deliberately prevent backend implementation, so this signed backend compiles against the matching package's lib/net10.0 assemblies. Assembly name/version/signing identity remain Avalonia.Native12.1.4.0. The distinct PackageId prevents a NuGet self-cycle; the main application's version is independent.

The original Avalonia.Native12.1.4 NuGet package supplies its unchanged macOS dylib through an explicit conditional Content item. Its managed assembly is excluded. The application references this source project and directly excludes official Native package assets, ensuring that one managed implementation is selected. Existing application code uses the public transfer contract; no reflection or guessed pasteboard name is introduced.

When updating Avalonia, update the wrapper source, package/native payload, assembly identity and MicroCom versions together from one fixed upstream release. Review the incoming PNG mapping and mounted-volume timer disposal first; remove each local functional patch when the upstream implementation contains its equivalent. Preserve the original license and review the final managed/native asset closure during the coordinated application build.
