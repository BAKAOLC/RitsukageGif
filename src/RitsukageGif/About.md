# RitsukageGif

$Version$

原型设计来自 Seiwell 制作的 SlimeGif，功能设计参考小炎酱的 SlimeGif ver 3.3 / 改 V3.61。

[项目主页](https://github.com/BAKAOLC/RitsukageGif)

## 使用

- 先选择录制区域，再开始录制。帧率、缩小倍率和输出格式在主界面调整。
- 选区时单击选择窗口，拖动选择范围，右键或 Enter 确认，Esc 返回。
- 设置中可切换屏幕画面和窗口内容采集。预设模板在外部编辑，导入后可绑定快捷键。
- 右键点击预览可再次复制，拖动预览可复制文件。

## 快捷键

- 开始 / 结束录制：$HotKey_RecordGif$
- 选择录制区域：$HotKey_SelectRegion$
