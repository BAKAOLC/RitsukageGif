# RitsukageGif

$Version$

用于截图、长截图、贴图和屏幕录制，支持图像标注、动图编辑与 rgscript 脚本。

原型设计来自 Seiwell 制作的 SlimeGif，功能设计参考小炎酱的 SlimeGif ver 3.3 / 改 V3.61。

[项目主页](https://github.com/BAKAOLC/RitsukageGif)

## 使用

主界面用于快速录制动图，可调整帧率、缩小倍率和输出格式。截图时可以直接标注、复制、保存、贴图或识别内容；截图工具栏中的录制使用独立的录制与预览流程。

快捷键、功能动作和鼠标操作可在设置中配置。外部预设可描述捕获范围、动态布局、输出位置和脚本流程，并绑定启动快捷键。

## 快捷键

- 快速录制开始 / 结束：$HotKey_RecordGif$
- 选择快速录制区域：$HotKey_SelectRegion$

- 增加 MP4、WebM 视频录制，支持系统音频与麦克风。
- 截图工具栏增加独立录制流程，支持普通与快速模式、延时开始、暂停、音频、摄像头、键鼠效果和现场标注；普通录制可预览、选择片段、调整播放速度、重录及导出 MP4、GIF、WebP。

- 增加 PNG、JPEG、BMP、WebP、AVIF 静态图保存，支持复制图像或图像文件、文件命名和同名处理；脚本可捕获单帧并保存到多个目标，包括 HDR PNG 和 EXR。

- 增加多语言文字识别（含日文）、二维码和条码识别、隐私区域检测及自动马赛克，识别组件可按需安装。
- 增加表格与公式识别，支持编辑结果、复制、打印及导出文档；可使用表格数据、HTML、Markdown、LaTeX、图像和 PDF 等输出。
- 增加截图、贴图、识别结果和剪贴板文本翻译，支持原文对照、图像翻译、自定义翻译服务及备用语言。文本和 HTML 贴图可在原文和译文之间切换，也可通过脚本控制。
- 重新整理设置、功能动作、全局与内置快捷键、鼠标操作和托盘菜单；支持设置即时生效、配置导入导出、隐藏到托盘及分别清理记录。
- 扩展截图、视频、标注、动图编辑、长截图、贴图、图像处理、剪贴板、翻译、识别、文档和设置的脚本接口；命令行支持传入脚本文件、脚本文本或标准输入，返回 JSON 结果，并可取消执行。

- 修复录制窗口局部时缩小窗口可能导致的崩溃。手动选择的窗口来源丢失时提示重新选择，并保留已录制内容。
- 改善多屏、高 DPI 和深浅色主题显示，统一工具属性面板与控件样式。
- 新增输出像素比例设置。普通截图和长截图可分别设置保存与复制的尺寸，录制也可单独设置。选择跟随显示缩放时，200% 缩放下的 4K 画面可输出为 1080p。
