# 动图编辑器

从主界面打开“编辑动图”，或使用命令行：

```text
RitsukageGif animation-editor "animation.webp"
```

也可以不传文件，创建一个空白画布。编辑器支持 GIF、WebP、APNG 和静态图片。导入文件会展开动画帧，尺寸不同时等比缩放并居中。

## 帧与时间

底部时间线显示帧缩略图和时长。按 Ctrl 或 Shift 选择多帧；勾选“全部帧”可对整个动画操作。

可添加空白帧、导入、复制、删除或前后移动帧。时长以毫秒设置；循环次数为 0 时无限循环。至少保留一帧。

“播放 / 停止”预览动画。GIF 的时间精度是 10 毫秒；其他格式可保留更细的时间。

## 画布与效果

“帧”页可调整宽高、裁剪、旋转和翻转，作用于全部帧。默认锁定宽高比。裁剪前，在“绘制”页选择“区域选择”，拖出需要保留的范围。

“效果”页提供局部或全图的马赛克、模糊、灰度、反色、亮度和对比度。没有选区时处理整个画面；效果作用于选中的帧。

## 绘制与水印

“绘制”页提供画笔、橡皮、直线、矩形和椭圆。橡皮擦除为透明。

文字和图片是可选择的草稿图层，可以拖动位置。选中文字后可修改内容、字号和颜色；图片可以修改尺寸与不透明度。需要删除时使用“删除选中图层”。

- “应用到当前帧”：将绘制和图层写入当前帧。
- “水印应用到所选帧”：把文字、图片水印叠加到所选帧，保留各帧原有内容。已有画笔修改时，先应用当前帧绘制。
- “放弃绘制草稿”：丢弃尚未应用的绘制与图层。

切换帧、播放或其他处理前需要应用或放弃草稿，以避免丢失修改。撤销和重做优先作用于草稿，其次作用于已经应用的编辑。

## 导出

可导出 GIF、WebP、APNG；PNG 只导出当前帧。默认文件名带 `-edited`，不会直接覆盖原文件。

GIF 可设置颜色数与抖动；WebP 可设置质量与无损模式。APNG 和 PNG 保留无损像素。导出到已有文件会要求确认覆盖，取消处理不会留下不完整的目标文件。

编辑过程使用临时帧文件和有数量上限的撤销历史。关闭时会清理临时数据；存在未导出的修改时会询问是否放弃。编辑器暂不保存可继续编辑的项目文件，导出后的文字和图层会合并到图像中。
