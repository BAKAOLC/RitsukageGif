# 动图编辑器

## 打开文件

在主界面点击“动图编辑器”，再从“文件 → 打开”选择图片。支持 GIF、WebP、APNG、PNG、JPEG 和 BMP；也可以用“文件 → 新建”创建空白画布。

命令行可直接打开文件：

```powershell
.\RitsukageGif.exe animation-editor "D:\Pictures\animation.gif"
```

## 编辑

底部时间线用于选择帧。按 Ctrl 点击可多选，按 Shift 点击可连续选择，Ctrl+A 选择全部帧。

- 在“帧”中添加、导入、复制、删除或调整帧顺序；“时长与循环”可修改所选帧的时长和动画循环次数，循环次数为 0 表示无限循环。
- 在“插入”中添加图片或文字。插入图片是叠加到画面；要把文件中的画面加入时间线，请用“帧 → 导入为新帧”。
- 在“绘制”中画线、画形状、涂画或擦除；在“图像”中调整尺寸、裁剪、旋转、翻转或添加效果。

绘制、图片和文字需要点击右侧的“应用”才会写入帧；“放弃”会丢弃当前草稿。添加水印时，可选中多帧，再把应用范围设为“所选帧”。已有画笔修改时只能应用到当前帧。

切换帧、播放或导出前，先应用或放弃草稿。可用撤销、重做恢复编辑。底部播放按钮用于预览；视图缩放只改变显示大小，导出尺寸需在“图像”中调整。

## 导出

选择“文件 → 导出”，设置格式和编码选项，再点击“导出”选择保存位置。

- GIF、WebP、APNG：导出整个动画。
- PNG：只导出当前帧。

默认文件名带 `-edited`；选择已有文件时会提示确认覆盖。导出后，文字和图片会合并到画面中。
