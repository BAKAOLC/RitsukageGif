# 动图编辑器

从主界面打开“编辑动图”，或使用命令行：

```text
RitsukageGif animation-editor "animation.webp"
```

不传文件时创建空白画布。可打开 GIF、WebP、APNG 和静态图片。

## 布局

顶部工具带按文件、帧、插入、绘制、图像、视图分类。中间是画布，右侧只显示当前工具的参数，底部是全宽帧时间线和播放定位栏。

工具属性可通过标题处“收起”隐藏，再点击工具或“视图 → 工具属性”打开；收起不会放弃草稿。视图缩放只影响显示，改变导出尺寸应使用“图像 → 缩放”。底部显示缩放比例、当前帧、选中帧数和所选帧总时长。

## 帧与时间

底部显示每帧缩略图和毫秒时长。按 Ctrl 或 Shift 选择多帧；点击“全选帧”或按 Ctrl+A 会实际选中时间线中的所有帧。批量操作只处理当前选中的帧。右键帧可添加、导入、复制、删除、调整顺序或打开时长参数。

“帧 → 时长与循环”调整所选帧时长和动画循环次数。循环次数为 0 时无限循环。至少保留一帧。

底部的首帧、上一帧、播放、下一帧、末帧用于定位和预览。“帧”工具带的前移、后移用于修改帧顺序。GIF 的时间精度是 10 毫秒；其他格式可保留更细的时间。

## 插入图片和文字

- **插入 → 插入图片**：在当前帧叠加图片，不增加帧数。
- **帧 → 导入为新帧**：展开文件中的动画帧并加入时间线，尺寸不同时等比缩放并居中。
- **插入 → 插入文字**：输入内容、字体、字号和颜色后插入文字图层。

图片和文字在应用前是独立草稿图层。选择图层后可拖动位置；图片四角手柄默认等比缩放，按住 Shift 自由缩放。右侧也可输入坐标、尺寸和不透明度，或调整前后层次、删除选中图层。选中文字可修改内容和样式。

侧栏底部的操作始终可见：

- 选择“当前帧”并点击“应用”：将绘制和图层写入当前帧。
- 选择“所选帧”并点击“应用”：把文字和图片叠加到所选帧，保留各帧原有内容。已有画笔修改时只能应用当前帧。
- “放弃”：丢弃尚未应用的绘制与图层。

切换帧、播放或其他处理前需要应用或放弃草稿。撤销和重做优先作用于草稿，其次作用于已应用的编辑。

## 画布与效果

“绘制”提供画笔、透明橡皮、直线、矩形、椭圆和区域选择。选择工具后，右侧显示对应的颜色、线宽或填充参数。

“图像”提供缩放、裁剪、旋转、翻转，作用于整个动画。裁剪前拖出需要保留的区域。“效果”提供马赛克、模糊、灰度、反色、亮度和对比度，作用于选中的帧；有区域选区时只处理该区域，没有选区时处理整个画面。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+O / Ctrl+S | 打开 / 导出 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+D / Ctrl+A | 复制所选帧 / 选择全部帧 |
| Delete | 删除选中图层；未选图层时删除所选帧 |
| Space | 播放 / 停止 |
| 左右方向键 | 上一帧 / 下一帧 |
| Home / End | 首帧 / 末帧 |

在文字、数字和下拉输入控件内操作时，编辑器不会抢占输入按键。

## 导出

“文件 → 导出”打开格式和编码参数。可导出 GIF、WebP、APNG；PNG 只导出当前帧。默认文件名带 `-edited`，不会直接覆盖原文件。

GIF 可设置颜色数与抖动；WebP 可设置质量与无损模式。APNG 和 PNG 保留无损像素。导出到已有文件会要求确认覆盖，取消处理不会留下不完整文件。

编辑过程使用临时帧文件和有数量上限的撤销历史，关闭时清理临时数据。存在未导出的修改时会询问是否放弃。编辑器暂不保存分层项目文件，导出后的文字和图层会合并到图像中。
