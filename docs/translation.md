# 翻译

可翻译截图识别的文字、贴图中的文字、识别结果及剪贴板文本。图像中的文字先在本机 OCR，再将文本发送给你配置的翻译服务。

## 配置服务

在“设置 → 常规 → 翻译”选择服务，填写完整请求地址：

| 服务 | 请求地址示例 |
| --- | --- |
| LibreTranslate | `https://你的服务/translate` |
| DeepL | `https://api-free.deepl.com/v2/translate` |
| Azure Translator | `https://api.cognitive.microsofttranslator.com/translate` |
| 兼容聊天接口 | `https://你的服务/v1/chat/completions` |

需要密钥时，输入后点击“保存密钥”。密钥使用系统保护存储，不会随配置导出。Azure 可填写区域，兼容聊天接口需要填写模型。

软件不附带服务账号或额度。服务支持的语言、收费和用量限制由对应提供方决定。语言代码可参见 [DeepL 语言接口](https://developers.deepl.com/docs/getting-started/supported-languages)和 [Azure 支持语言](https://learn.microsoft.com/azure/ai-services/translator/language-support)。

## 使用

在截图工具栏的更多操作中选择“翻译”，或在贴图、识别结果中选择翻译。也可在功能动作中配置“截图并翻译”和“翻译剪贴板”的快捷键。

截图选区结束后会打开独立的翻译窗口，仍可继续截图或操作原窗口。修改源语言或目标语言会重新翻译；修改原文后点击翻译。正在请求时可停止，失败后可重试。

在翻译设置中选择默认模式：

- **图像到文本**：识别整张图的文字，再翻译为可选择、复制的文本。源语言与目标语言相同时，可使用设置中的备用语言。
- **图像到图像**：按识别出的文字区域翻译，在相应位置清除原文字并绘制译文。可切换文字和图像、仅图像、仅文字三种视图，也可切换原图与译图，缩放、拖动画面。复制图像会复制当前显示的原图或译图的完整图像。修改原文时需保留各文字区域的分行。

在图像上拖过文字可选择并复制该段文字；拖动空白处移动画面。切换原图与译图后会清除原来的文字选择。原图的字形位置依据 OCR 文字框估算。

原文和译文可分别复制。图像模式不会覆盖原始文件；文字区域的位置来自本机 OCR，实际识别效果取决于文字、字体和背景。翻译服务只接收识别的文字，不接收原始图像。服务不需要单独支持图像翻译接口，但按文字区域翻译可能产生多次文本请求，仍受服务的用量限制。

## 朗读

原文和译文标题旁的喇叭按钮可朗读对应内容。再次点击同一个按钮会停止，点击另一侧会切换朗读内容；关闭翻译窗口也会停止。

朗读使用本机已安装的系统语音，不需要翻译服务的语音账号。Windows 使用系统语音合成，Linux 使用 `espeak-ng`，macOS 使用 `say`。未安装相应引擎或语言语音时，按钮会显示不可用原因。

只有执行翻译操作后才发送翻译请求，打开设置不会发送图像或文本。
