# 后续计划

以下能力尚未实现，不代表当前版本支持。

- 桌面贴图扩展：支持动态图片和其他内容类型。静态贴图的分组、锁定、Windows 鼠标穿透与会话恢复已提供，见[截图与长截图](screenshots.md#桌面贴图)。
- 音视频扩展：补齐其他平台的系统声音与麦克风捕获。现有 SDR/HDR MP4/WebM 和 Windows 音频录制见[音视频录制](video-recording.md)。
- HDR 支持范围：补齐编辑器与截图标注画布的原生 HDR 预览、长截图、多路录制及其他平台的 HDR 路径。主界面的 Windows PQ PNG/APNG 原生预览已接入，仍需真实 HDR 显示器验证高光亮度与跨屏视觉效果；目前跨屏窗口按主要所在显示器选择模式。
- 全局鼠标的平台支持：扩展到 Windows 以外的平台。全局动作、功能内键位与鼠标配置、Windows 全局鼠标绑定已提供，见[快捷键与鼠标操作](screenshots.md#快捷键与鼠标操作)。
