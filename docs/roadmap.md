# 后续计划

以下能力尚未实现，不代表当前版本支持。

- 桌面贴图扩展：补充文本、文件集合等内容类型。GIF、APNG、WebP 动图的播放、暂停、逐帧与原文件输出见[截图与长截图](screenshots.md#桌面贴图)。
- 音视频扩展：补齐其他平台的系统声音与麦克风捕获。现有 SDR/HDR MP4/WebM 和 Windows 音频录制见[音视频录制](video-recording.md)。
- HDR 支持范围：补齐动图编辑器、截图现场与贴图标注的 HDR 内容预览，以及长截图、多个独立录制流和其他平台的 HDR 路径。已有预览与输出范围见[HDR 预览](screenshots.md#hdr-预览)；仍需真实 HDR 显示器验证高光亮度与跨屏视觉效果。
- 全局鼠标的平台支持：扩展到 Windows 以外的平台。全局动作、功能内键位与鼠标配置、Windows 全局鼠标绑定已提供，见[快捷键与鼠标操作](screenshots.md#快捷键与鼠标操作)。
- Steam 集成：评估平台入口和相关能力；当前版本不包含 Steam 接入。
