# 功能动作脚本

[返回手册](README.md)

在设置的“功能动作”中新增动作，选择脚本类型，即可直接编写 rgscript。动作可绑定全局快捷键、加入托盘菜单，并配置忽略的程序。外部预设仍通过“运行预设”动作选择。

编辑区提供行号、着色、补全和参数提示。测试会实际执行当前内容，并显示输出及错误行列；“停止脚本”取消本次执行，不会自动取消正在进行的录制。关闭动作窗口也会取消未完成的脚本。保存只保存动作配置，不执行脚本。

## 调用已有动作

```rgscript
return actions.run(ActionKind.ShowMainWindow);
```

`actions.run(kind: ActionKind, options?: ActionOptions)` 返回 `Result<void, string>`。成功值为空，失败值为错误信息。可用 `?` 传播错误，或自行处理返回结果。当前状态不允许操作时，同样返回错误。

`ActionKind` 包含可调用的标准动作，可通过补全查看。内联脚本动作不在这个枚举中，避免脚本动作递归调用自身。

`ActionOptions` 可选字段：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `parameter` | `string` | 捕获来源或文件路径，由所选动作决定 |
| `preset` | `string` | 外部文件中的预设名称 |
| `arguments` | `object` | 所选动作的参数；值为字符串、布尔或有限数值 |

标准动作显示对应的只读脚本，方便查看实际参数；选择脚本类型后可直接编辑代码。动作名称和类型仍可修改。

## 自定义截图区域

截图动作可设置延迟、固定尺寸、固定位置及宽高比。未固定位置时，固定尺寸以延迟结束后的鼠标位置为中心；固定位置使用屏幕像素坐标，允许负坐标。宽高比约束后续调整，不会强制改变初始范围。

脚本调用时，截图动作的 `arguments` 支持：

| 参数 | 类型 | 范围 |
| --- | --- | --- |
| `delay` | 数值 | 0–86400 秒 |
| `x`, `y` | 整数 | −99999–99999，须同时提供 |
| `width`, `height` | 整数 | 1–99999，须同时提供 |
| `ratio` | 数值 | 大于零的有限宽高比 |

只提供位置而未提供尺寸，不会建立固定选区。当前窗口、上次区域等已有明确目标的动作保留该目标。

## 与预设的关系

动作脚本使用相同的 rgscript 语法和已注册的文件、图像、媒体、捕获与识别服务。内联代码不需要写入临时文件；相对路径以程序当前工作目录为基准。

内联脚本运行不会替换当前预设，也不会在脚本正常结束时自动停止录制。例如 `record.start();` 可以只开始录制，由用户稍后停止。需要结束录制时，应显式调用 `record.stop()`。
