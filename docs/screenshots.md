# 截图与长截图

从托盘菜单选择“截图”，也可以在设置中绑定截图快捷键或添加截图动作。截图快捷键默认未绑定。

## 选择与标注

录屏选区完成后，可以点击选区旁操作栏的勾选按钮确认，或点击叉号退出选区；Enter 和 Esc 仍可使用。拖动、调整范围时会暂时隐藏操作栏，松开后重新显示。

移动鼠标预览候选窗口或控件，单击选中，或拖动划定范围。选中后可以直接标注，不必打开独立编辑器。选区现场提供鼠标入图、窗口／控件识别和屏幕／窗口来源开关，修改会记入共用捕获偏好。

- 拖动选区内部移动范围，拖动边缘手柄调整大小。
- 方向键移动一个像素；Ctrl + 方向键向对应边扩大，Shift + 方向键从对应边缩小。
- Tab 切换窗口与控件识别；W、A、S、D 微调鼠标位置。屏幕上下文与窗口内容可在现场切换，默认未绑定切换快捷键。
- 反引号切换鼠标是否入图。仅在捕获来源支持切换时可用。
- F1 切换完整、精简和隐藏提示；Shift + Tab 切换边缘吸附模式。
- 右键或 Esc 逐步取消当前操作、清除选区或退出。清除选区后仍可继续选择。

截图可以使用画笔、箭头、矩形、椭圆、高亮、文字和马赛克。Ctrl + Z 撤销，Ctrl + Y 重做；Ctrl + C 复制，Ctrl + S 保存。Enter 或双击也可完成截图。工具的快捷键显示在按钮提示中。

切换到选择工具后，可以选中标注并拖动、删除，选中文字后可以修改内容、字号和颜色。标注编辑支持撤销和重做。以上是默认快捷键；设置中的“内置快捷键”按使用场景分组，每项可修改或清除一个绑定，也可恢复默认；冲突会标出对应动作。全局快捷键单独配置。

工具属性显示在工具条下方，随当前工具切换。选择文字工具后在画面上单击输入；Enter 提交，Shift + Enter 换行，Esc 放弃本次修改。选择工具中双击已有文字可重新编辑。

从工具条的“更多”菜单可调整功能按钮和标注按钮，也可从设置中的截图、标注页面打开。功能按钮支持拖动排序，分别选择显示在工具条、放入更多菜单或隐藏；标注工具可拖动分组和排序。同组工具共用一个按钮，通过旁边的下拉切换。保存后生效，取消保留原配置。

工具条默认贴近选区，空间不足时翻到选区上方。拖动左侧把手可手动放置，双击把手恢复自动位置。框边按钮固定在选区附近，不会为了避开鼠标而移动。

选框旁的四个按钮分别控制圆角、保持纵横比、阴影或边框、刷新画面。圆角和装饰可展开调整数值与颜色；“每次截图启用”只记忆阴影或边框，圆角独立记忆。Windows 上按住刷新按钮查看实时画面，松开重新冻结；其他平台使用单次刷新。保存、复制和贴图使用相同的圆角与装饰，阴影和外边框会增加图像四周的透明留白。

保存支持 PNG、JPEG、BMP 和静态 WebP。取消保存对话框会回到原来的选区与标注。

## 快捷键与鼠标操作

主设置中的有效修改立即生效，停止修改约 3 秒后自动保存；关闭设置时保存尚未写入的更改。管理员权限偏好在下次启动新进程时生效。工具栏和预设等独立编辑器仍使用保存／取消。

设置窗口可以保持打开，不会阻止主界面或全局动作。只有快捷键录入框获得焦点时，才会暂时暂停全局快捷键；离开录入框后按原有配置恢复。在选区或贴图中修改的偏好，不会被设置窗口中其他选项的修改覆盖。

设置中按作用范围分别配置：

| 配置 | 用途 |
| --- | --- |
| 全局动作 | 添加选区、截图、开始或停止录制、运行预设、打开编辑器或录制目录等动作，分别设置快捷键和托盘入口。预设动作可以指定名称与参数。 |
| 内置快捷键 | 按选区、截图、长截图、贴图等场景调整键位，每项一个绑定。 |
| 鼠标 | 自定义贴图中的鼠标操作及修饰键，可用手势取决于动作。 |
| 全局鼠标 | 在 Windows 中用修饰键加鼠标拖动执行动作，拖动范围直接作为截图或录制区域。 |

功能内绑定只在对应界面生效；全局绑定用于程序没有焦点时。冲突会在设置中提示。功能动作使用同一份列表管理快捷键与托盘入口，每行可编辑或删除；清空动作立即生效，重新打开不会添加默认项，需要时可以恢复本页默认值。

配置导入和导出使用当前 JSON 格式。

全局鼠标绑定默认为空，不能绑定不带修饰键的鼠标操作。页面直接提供截图并贴图、截图并复制、截图并复制文字、快速保存截图、截图、长截图和开始录制七项；已有鼠标绑定的自定义动作也会显示。

## 桌面贴图

使用“贴图”将结果固定到桌面。拖动移动，滚轮缩放，Ctrl + 滚轮调整透明度；右键可以复制、保存、恢复实际大小、隐藏或关闭。默认 Esc 关闭贴图，可用“恢复上次关闭的贴图”找回。隐藏的贴图可从托盘重新显示。

右键菜单可以创建或选择分组、显示或隐藏同组贴图，以及锁定位置与缩放。Windows 上还可以启用鼠标穿透，让点击落到下层窗口；此功能需要可用的托盘恢复入口。重新显示贴图会解除穿透与锁定，方便再次操作。

设置中的贴图恢复开关默认开启。下次启动可恢复未关闭的静态贴图、分组、位置、缩放、透明度、锁定与隐藏状态；鼠标穿透不会跨启动保留。超出屏幕的长图可通过滚动条浏览，缩放不会改变保存和复制时的原始像素。HDR 贴图保留原始 HDR 数据，保存和复制不会强制降为 SDR；显示条件见下文。目前不播放动态贴图。

## 识别隐私区域

在截图或贴图标注的马赛克工具组中选择“识别隐私区域”，检测当前图像中的文字与二维码。设置中的“自动处理隐私马赛克”决定是否默认选中识别到的邮箱、电话、通过格式校验的身份证号和支付卡号，以及二维码；普通文字保留为可选候选。

点击候选区域切换选择，选择“应用马赛克”后整批写入标注，可一次撤销。取消不会修改原图。检测在本机进行，二维码边界为保守估计；识别不能保证发现所有敏感内容，请检查候选范围。缺少文字识别能力时仍可检测二维码。

## 长截图

选好范围后，从工具栏的长截图按钮进入，也可按 L。原选区的位置和大小保持不变，范围内可以直接滚动目标内容；Windows 下范围外继续显示遮罩。进入后自动采集，不需要再点开始；现场可以切换竖向或横向。捕获框尺寸固定，只能沿拼接方向移动；实时预览显示已拼接的长图；剪刀菜单可按当前画面裁掉前面或后面的多余内容。

控制条和预览显示在操作所在屏幕内。拖动控制条左侧把手可以移动工具条；双向箭头用于沿当前记录轴移动捕获框。在 Windows 上，将焦点交给滚动目标后，长截图快捷键仍可使用，不需要先点击控制条；这些按键只在本次长截图期间生效。打开下拉菜单或裁剪设置时，按键优先交给其中的控件。

滚动目标内容，预览会显示已记录的图像。滚动过快、重复纹理或画面变化导致无法匹配时，不会强行拼接。返回已记录画面附近，找到重叠内容后可以继续。

可以暂停、继续，或直接复制、保存、快速保存、贴图、识别文字；需要标注时选择编辑长图。取消会结束本次捕获，不返回原截图。已有标注时需要先删除或撤销标注再开始长截图，避免标注对应到错误的内容。

长截图的默认按键可在内置快捷键页面修改：

| 按键 | 操作 |
| --- | --- |
| Alt+1 | 自动滚动 |
| Alt+2 | 裁掉当前画面之前的内容 |
| Alt+3 | 裁掉当前画面之后的内容 |
| Alt+4 | 暂停或继续 |
| Alt+5 | 编辑长图 |
| Enter | 复制并结束 |
| Esc | 结束本次捕获 |

长截图使用 SDR。在截图工具栏选择 SDR 后即可开始，不必退出截图修改全局设置。

窗口内容模式保持窗口来源；窗口丢失、范围越界或捕获时窗口尺寸改变会暂停，不会改为抓取下层屏幕。

采集故障会暂停并显示原因，界面和已记录的图像会保留。恢复目标后可以继续尝试；已有内容时也可以直接输出当前长图，或取消本次捕获。

## 托盘与颜色

托盘菜单可以恢复主界面、截图、开始或停止录制、打开视频录制窗口以及退出，也可显示自定义全局动作。设置中可分别启用关闭主界面或最小化时隐藏到托盘。隐藏窗口不会停止录制。MP4、WebM 与系统声音、麦克风的使用方式见[音视频录制](video-recording.md)。

Windows 截图和单路录制共用捕获颜色偏好，可选择 SDR、HDR 或同时输出两者。两份输出使用同次捕获的数据；HDR 原始帧保留在线性浮点格式中，SDR 单独进行色调映射。

- SDR 截图支持 PNG、JPEG、BMP、静态 WebP；录制沿用 GIF、WebP、APNG。
- HDR 截图支持 16 位 Rec.2020/PQ PNG 和线性 HALF OpenEXR；HDR 录制使用 16 位 PQ APNG。查看软件也需要支持对应的 HDR 色彩信息。
- 同时保存截图时生成 `.sdr.png` 和 `.hdr.png` 两份文件，文件冲突按保存设置中的覆盖或重命名规则处理。
- SDR 色调映射可选高光压缩或参考白点。该选项不改变 HDR 原始亮度。

当前 HDR 捕获需要 Windows 提供真实 HDR 来源。其他平台、多路录制、长截图及特殊反色鼠标图形的 HDR 路径尚不支持。截图工具栏可选择本次保存的颜色模式，只有来源支持时才能选择 HDR；复制和贴图也保留所选颜色模式的 HDR 数据。剪贴板同时提供兼容的 SDR 位图，实际粘贴效果取决于目标软件读取的格式及 HDR 支持。

主界面预览、选区背景和 HDR 贴图已接入 Windows 原生 HDR 显示。主界面预览带 HDR 色彩信息的 PQ PNG/APNG 时，在系统已开启 HDR 且显示通道可用的显示器上使用浮点 scRGB 显示；否则回退到 SDR 映射。窗口移屏、DPI 和系统显示设置变化会重新判断。跨屏窗口按主窗口主要所在的显示器选择模式，不会把同一个预览按显示器拆分。透明像素在 HDR 预览中合成到黑色背景，原文件透明度不变。

HDR 贴图同样需要系统 HDR 与可用的显示通道，否则显示 SDR 映射。动图编辑器、截图标注和贴图标注画布仍使用 SDR 预览；HDR 贴图应用标注后仍保留 HDR 输出。OpenEXR 不属于上述主界面原生预览支持范围。真实 HDR 显示器上的高光亮度和跨屏视觉效果尚待实机验证。

## 命令行与脚本

使用 `screenshot` 打开截图选区；`screenshot screen` 或 `screenshot window` 指定屏幕上下文或窗口内容。

脚本保存单帧请参阅[静态截图服务](services.md#保存静态截图)。
