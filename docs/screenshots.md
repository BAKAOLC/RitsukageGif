# 截图与长截图

从托盘菜单选择“截图”，也可以在设置中绑定截图快捷键或添加截图动作。截图快捷键默认未绑定。

## 选择与标注

录屏选区完成后，可以点击选区旁操作栏的勾选按钮确认，或点击叉号退出选区；Enter 和 Esc 仍可使用。拖动、调整范围时会暂时隐藏操作栏，松开后重新显示。

移动鼠标预览候选窗口或控件，单击选中，或拖动划定范围。选中后可以直接标注，不必打开独立编辑器。选区现场提供鼠标入图、窗口／控件识别和屏幕／窗口来源开关，修改会记入共用捕获偏好。

- 拖动选区内部移动范围，拖动边缘手柄调整大小。
- 方向键移动一个像素；Ctrl + 方向键向对应边扩大，Shift + 方向键从对应边缩小。
- Tab 切换窗口与控件识别；W、A、S、D 微调鼠标位置。屏幕上下文与窗口内容可在现场切换，默认未绑定切换快捷键。
- 反引号切换鼠标是否入图。仅在捕获来源支持切换时可用。
- F1 切换完整、精简和隐藏提示；Shift + Tab 切换边缘吸附模式。
- 右键或 Esc 逐步取消当前操作、清除选区或退出。清除选区后仍可继续选择。

截图可以使用画笔、箭头、矩形、椭圆、高亮、文字和马赛克。Ctrl + Z 撤销，Ctrl + Y 重做；Ctrl + C 复制，Ctrl + S 保存。Enter 或双击也可完成截图。工具的快捷键显示在按钮提示中。

启用二次编辑时，使用对应工具点击已有标注即可选中、拖动和修改，不必先切换到选择工具。再次点击当前工具退出标注，回到选区操作；也可使用内置快捷键切换二次编辑。二次编辑策略可设为启用、禁用、完全禁用或仅文字。选中文字后可以修改内容、字号和颜色；标注编辑支持撤销和重做。以上是默认快捷键；设置中的“内置快捷键”按使用场景分组，每项可修改或清除一个绑定，也可恢复默认；冲突会标出对应动作。全局快捷键单独配置。

工具属性显示在工具条下方，随当前工具切换。选择文字工具后在画面上单击输入；Enter 提交，Shift + Enter 换行，Esc 放弃本次修改。选择工具中双击已有文字可重新编辑。选中折线后可拖动各个节点；绘制折线时，右键或双击左键完成。编号以点击位置为中心放置。

“更多”菜单的“调整”管理功能按钮；工具组下拉菜单的“调整”管理标注工具，也可从设置进入。功能按钮支持拖动排序，分别选择显示在工具条、放入更多菜单或隐藏；标注工具可拖动分组和排序。同组工具共用一个按钮，通过旁边的下拉切换；右键也可展开该组，滚轮切换组内工具。工具组未激活时，滚轮只更换记忆项。保存后生效，取消保留原配置。

工具条默认贴近选区，空间不足时翻到选区上方。拖动左侧把手可手动放置，双击把手恢复自动位置。框边按钮固定在选区附近，不会为了避开鼠标而移动。

选框旁的四个按钮分别控制圆角、保持纵横比、阴影或边框、刷新画面。圆角和装饰可展开调整数值与颜色；“每次截图启用”只记忆阴影或边框，圆角独立记忆。Windows 上按住刷新按钮查看实时画面，松开重新冻结；其他平台使用单次刷新。保存、复制和贴图使用相同的圆角与装饰，阴影和外边框会增加图像四周的透明留白。

保存支持 PNG、JPEG、BMP、静态 WebP 和 AVIF。PDF 使用独立的[文档导出](document-output.md)，可选择纸张和分页。取消保存对话框会回到原来的选区与标注。

## 选区测量

按住 Alt 显示测量辅助线；也可在设置的截图页面将辅助线设为始终显示，或关闭其中的“选区尺寸与间距”。普通操作时不常驻这些数值。

测量随光标位置选择参照：启用控件感知后，指向控件时优先测量控件，离开控件后使用窗口或当前屏幕。只显示选区宽高和当前方向的相关间距，不同时展开所有参照。拖动边或角时可查看对应方向的距离。连线旁的数字使用实际像素，跨屏与高 DPI 下不改用逻辑尺寸。测量内容不会进入输出图像。

手动选择窗口目标后，若窗口关闭或所选范围已不可用，程序停止采集并完成已有帧的编码，提示重新选择区域。此提醒仅针对手动目标；脚本与预设仍按其源丢失策略处理，不弹出此提醒。

## 快捷键与鼠标操作

主设置中的有效修改立即生效，停止修改约 3 秒后自动保存；关闭设置时保存尚未写入的更改。管理员权限偏好在下次启动新进程时生效。工具栏和预设等独立编辑器仍使用保存／取消。

设置窗口可以保持打开，不会阻止主界面或全局动作。只有快捷键录入框获得焦点时，才会暂时暂停全局快捷键；离开录入框后按原有配置恢复。在选区或贴图中修改的偏好，不会被设置窗口中其他选项的修改覆盖。

设置中按作用范围分别配置：

| 配置 | 用途 |
| --- | --- |
| 功能动作 | 添加选区、截图、开始或停止录制、运行预设、打开编辑器或录制目录等动作，分别设置快捷键和托盘入口。预设动作可以指定名称与参数，也可编写并测试[内联脚本](action-scripts.md)。 |
| 内置快捷键 | 按选区、截图、长截图、贴图等场景调整键位，每项一个绑定。 |
| 鼠标 | 自定义贴图中的鼠标操作及修饰键，可用手势取决于动作。 |
| 全局鼠标 | 在 Windows 中用修饰键加鼠标拖动执行动作，拖动范围直接作为截图或录制区域。 |

功能内绑定只在对应界面生效；全局绑定用于程序没有焦点时。冲突会在设置中提示。功能动作使用同一份列表管理快捷键与托盘入口，每行可编辑或删除；清空动作立即生效，重新打开不会添加默认项，需要时可以恢复本页默认值。

配置导入和导出使用当前 JSON 格式。

全局鼠标绑定默认为空，不能绑定不带修饰键的鼠标操作。页面直接提供截图并贴图、截图并复制、截图并复制文字、截图并翻译、截图并复制码内容、截图并快速保存、截图、长截图和开始录制九项；已有鼠标绑定的自定义动作也会显示。

## 桌面贴图

使用“贴图”将结果固定到桌面。拖动移动，滚轮缩放，Ctrl + 滚轮调整透明度；右键可以复制、保存、恢复实际大小、隐藏或关闭。默认 Esc 关闭贴图，可用“恢复上次关闭的贴图”找回。隐藏的贴图可从托盘重新显示。

右键菜单可以创建或选择分组、显示或隐藏同组贴图，以及锁定位置与缩放。Windows 上还可以启用鼠标穿透，让点击落到下层窗口；此功能需要可用的托盘恢复入口。重新显示贴图会解除穿透与锁定，方便再次操作。

设置中的贴图恢复开关默认开启。下次启动可恢复未关闭的贴图、分组、位置、缩放、透明度、锁定与隐藏状态；鼠标穿透不会跨启动保留。超出屏幕的长图可通过滚动条浏览，缩放不会改变图像的像素尺寸。HDR 贴图保留原始 HDR 数据，保存和复制不会强制降为 SDR。

“设置 → 贴图 → 复制和保存的内容”可选择当前图像或创建时原图。标注、旋转和其他编辑不会改写原图；原图和编辑结果均随会话保存。当前图像仍可按“只复制可见区域”处理缩略视口。

GIF、APNG、WebP 动图贴图按帧时长播放。右键可暂停、播放、切换前后帧和调整速度；隐藏后暂停，显示时继续。普通复制和保存取得当前显示帧；“复制原动图”“保存原动图”保留原始编码文件。开始标注或变换时冻结当前帧，避免后续播放覆盖编辑。

## 识别隐私区域

在截图或贴图标注的马赛克工具组中选择“识别隐私区域”，检测当前图像中的文字与二维码。设置中的“自动处理隐私马赛克”决定是否默认选中识别到的邮箱、电话、通过格式校验的身份证号和支付卡号，以及二维码；普通文字保留为可选候选。

点击候选区域切换选择，选择“应用马赛克”后整批写入标注，可一次撤销。取消不会修改原图。检测在本机进行，二维码边界为保守估计；识别不能保证发现所有敏感内容，请检查候选范围。缺少文字识别能力时仍可检测二维码。

## 长截图

选好范围后，从工具栏的长截图按钮进入，也可按 L。原选区的位置和大小保持不变，范围内可以直接滚动目标内容；Windows 下范围外继续显示遮罩。进入后自动采集，不需要再点开始；现场可以切换竖向或横向。捕获框尺寸固定，只能沿拼接方向移动；实时预览显示已拼接的长图；剪刀菜单可按当前画面裁掉前面或后面的多余内容。

控制条和预览显示在操作所在屏幕内。拖动控制条左侧把手可以移动工具条；双向箭头用于沿当前记录轴移动捕获框。在 Windows 上，将焦点交给滚动目标后，长截图快捷键仍可使用，不需要先点击控制条；这些按键只在本次长截图期间生效。打开下拉菜单或裁剪设置时，按键优先交给其中的控件。

滚动目标内容，预览会显示已记录的图像。滚动过快、重复纹理或画面变化导致无法匹配时，不会强行拼接。返回已记录画面附近，找到重叠内容后可以继续。

可以暂停、继续，或直接复制、保存、快速保存、贴图、识别文字；需要标注时选择编辑长图，在原截图界面继续编辑，保留原始 HDR 数据与输出模式。取消会结束本次捕获，不返回原截图。已有标注时需要先删除或撤销标注再开始长截图，避免标注对应到错误的内容。

长截图的默认按键可在内置快捷键页面修改：

| 按键 | 操作 |
| --- | --- |
| Alt+1 | 自动滚动 |
| Alt+2 | 裁掉当前画面之前的内容 |
| Alt+3 | 裁掉当前画面之后的内容 |
| Alt+4 | 暂停或继续 |
| Alt+5 | 编辑长图 |
| Enter | 复制并结束 |
| Esc | 结束本次捕获 |

长截图沿用本次捕获的 SDR、HDR 或同时输出模式，无需另设颜色选项。HDR 使用来源提供的浮点数据，与 SDR 按相同的匹配位置、裁剪范围和撤销步骤拼接。来源不再提供 HDR 数据时会暂停并显示原因，已拼接内容仍可输出；恢复来源后可继续，不会自动降为 SDR。

窗口内容模式保持窗口来源；窗口丢失、范围越界或捕获时窗口尺寸改变会暂停，不会改为抓取下层屏幕。

采集故障会暂停并显示原因，界面和已记录的图像会保留。恢复目标后可以继续尝试；已有内容时也可以直接输出当前长图，或取消本次捕获。

## 托盘与颜色

托盘菜单可以恢复主界面、截图、开始或停止录制、打开视频录制窗口以及退出，也可显示自定义全局动作。设置中可分别启用关闭主界面或最小化时隐藏到托盘。隐藏窗口不会停止录制。MP4、WebM 与系统声音、麦克风的使用方式见[音视频录制](video-recording.md)。

截图、长截图、动图录制和视频录制共用捕获颜色偏好，可选择 SDR、HDR 或同时输出两者。HDR 需要来源提供真实的浮点数据；不会把普通 SDR 图像作为 HDR 原图输出。同时输出的两份文件使用同次捕获的数据，SDR 单独进行色调映射。

| 输出 | 格式 |
| --- | --- |
| SDR 截图 | PNG、JPEG、BMP、静态 WebP、AVIF |
| HDR 截图 | 16 位 Rec.2020/PQ PNG、线性 HALF OpenEXR |
| SDR 动图 | GIF、WebP、APNG |
| HDR 动图 | 16 位 PQ APNG |
| SDR 视频 | MP4（H.264）、WebM（VP9） |
| HDR 视频 | MP4（HEVC Main10）、WebM（VP9 Profile 2），需要 FFmpeg 对应的 10 位编码器 |

同时保存截图时生成 `.sdr.png` 和 `.hdr.png` 两份文件，冲突时按保存设置处理。视频的文件命名与编码条件见[音视频录制](video-recording.md)。SDR 色调映射可选高光压缩或参考白点，不改变 HDR 原始亮度。

Windows 屏幕与窗口可捕获 HDR；Apple Silicon 的 macOS 15 及更新版本支持原生 HDR 捕获，较旧系统输出 SDR。Linux 按合成器实际提供的像素格式和色彩信息保留 HDR。长截图和预设布局继续保留来源的 HDR 数据。外部媒体与输入信道按自身解码格式进入布局，普通 8 位图像不会恢复出原本没有的 HDR 高光。

截图工具栏可以选择本次输出的颜色模式；只有来源支持时才能选择 HDR。复制和贴图保留所选模式的 HDR 数据，剪贴板同时提供兼容的 SDR 位图；粘贴结果取决于目标软件读取的格式及 HDR 支持。普通彩色鼠标可叠加到 HDR 截图；依赖背景反色的特殊鼠标图形不支持 HDR 截图输出，可关闭鼠标入图后输出。

### HDR 预览

各视图的颜色处理如下。原生 HDR 显示需要 Windows 已开启系统 HDR 且显示通道可用；不满足条件时使用 SDR 映射。窗口移屏、DPI 和系统显示设置变化会重新判断。预览模式不会改变保存模式或原始数据。

| 视图 | 显示方式 |
| --- | --- |
| 主界面预览 | 带 HDR 色彩信息的 PQ PNG/APNG 使用 HDR；OpenEXR 不在此预览范围内 |
| 截图与录屏选区 | 背景保留 HDR；现场标注与放大镜使用 SDR，RGB/HEX 取色也是映射后的值 |
| 静态图像编辑器 | 图像和已绘制标注合成 HDR 预览；输入文字或裁剪条带时暂用 SDR，结束后恢复 |
| 静态、动态与窗口贴图 | 有 HDR 数据时显示 HDR；进入贴图标注时暂用 SDR，应用后恢复 HDR，输出保留 HDR 数据 |
| 动图编辑器 | 编辑画布使用 SDR 预览 |
| 长截图 | 保留原始 HDR 数据进行拼接与输出；采集预览和编辑画布可显示 HDR，输入文字时暂用 SDR，结束后恢复 |

主界面和贴图的预览按窗口主要所在的显示器选择模式；跨屏窗口不会按显示器拆分。同一选区跨屏时，各屏背景分别按其能力显示。主界面与普通贴图将透明像素显示在黑底上；静态图像编辑器使用棋盘格，原始透明度均保留。真实 HDR 显示器上的高光亮度与跨屏视觉效果仍需实机验证。

## 平台与权限

macOS 使用系统屏幕录制权限；控件检测和自动滚动还需要对应的辅助功能权限。Retina 捕获保留原始像素密度，选区位置仍使用系统坐标，缩小倍数只应用一次。

Wayland 使用系统捕获对话框授权的屏幕或窗口。已授权窗口可用于多个区域和布局，但不能搜索或捕获尚未授权的其他窗口。自动滚动需额外授权指针控制，取消授权不会替换当前画面。X11 控件检测通过 AT-SPI，自动滚动通过 XTest；对应服务或权限不可用时会说明原因。

## 清除记录

从托盘菜单打开“清除记录”，可分别选择截图历史、选区历史、贴图历史和当前贴图。勾选需要清理的项目后点击“清除”。

## 命令行与脚本

使用 `screenshot` 打开截图选区；`screenshot screen` 或 `screenshot window` 指定屏幕上下文或窗口内容。

脚本保存单帧请参阅[静态截图服务](services.md#保存静态截图)。
